# Gemini 퀴즈 프롬프트 생성

**직접 퀴즈를 내지 마라.** 사용자가 Gemini에 붙여넣을 프롬프트를 만들어 주는 것이 이 작업이다.

## 절차

1. `guide/gemini-quiz.md`를 읽는다 (프롬프트 템플릿이 있다).
2. 방금 학습한 내용을 파악한다: 어느 Step/Unit인지, 핵심 문법 규칙, 타겟 어휘. 대화에 정보가 부족하면 사용자에게 물어본다 (교재 PDF는 이 폴더에 없으므로 필요하면 내용을 붙여넣어 달라고 한다). 진도 맥락은 `guide/tutor.md`의 로드맵 참고.
3. 템플릿의 `{ }` 자리를 채워 완성한다:
   - `[타겟 문법]` — 학습한 핵심 문법 규칙 요약
   - `[타겟 어휘]` — 영어-스페인어 매칭 리스트
4. **코드 블록 안에 프롬프트 텍스트만** 출력한다. 코드 블록 밖 설명은 한두 줄로 최소화.

## 규칙

- 예문은 담백한 사실 기반만. 억지 상황·개인 취미 가정 금지 (템플릿에도 이미 명시됨 — 지우지 마라).
- 난이도: SNULT 3급 상(DELE B2 진입) 수준.
